## Current cache and privacy audit, 2026-10-17

The Production read-only inventory reports 7 products (6 published), 6 active public R2 covers, 26 active public R2 gallery images, 1 active R2-private cover, 2 active R2-private gallery images, 3 active Supabase videos, and 2 active premium assets in Supabase with `is_public=false`. There are 3 categories and none has an assigned image. The Lamilia Supabase project reports the four media migrations `20261008120000`, `20261008224035`, `20261009113000`, and `20261010184114` as applied; the project has no development branches.

Anonymous Production GETs against one active premium asset returned `401` from `/api/downloads/<asset>` and `404` from `/api/media/<asset>`, both with `Cache-Control: no-store`; its identifier is intentionally omitted here. No premium bytes or signed URL were returned.

The public media origin returned `Cache-Control: public, must-revalidate, max-age=14400, s-maxage=60` (four-hour browser freshness). A current Production browser sample at desktop DPR2 rendered the gallery at 598 CSS pixels while selecting a Next optimizer candidate of 640 source pixels; the 1533×2000 R2 original is large enough for the 1196-pixel DPR2 target. A read-only optimizer request returned `X-Vercel-Cache: STALE`, `Age: 18277`, and a 640×835 image. This is evidence of an undersized transformed candidate and stale optimizer response; it does not prove the optimizer returned the wrong original image. No cache purge or Production change was made. The dated public probe decoded all four images in each context and had no console/page errors or HTTP error responses; its desktop-DPR2 run is marked `FAIL` because two JavaScript chunk requests were canceled during navigation. Direct HEAD retries for those chunks returned HTTP 200, so that run is not treated as a clean browser PASS. Public screenshots and full diagnostics from the probe remain in the local `public-quality-run-20261017/` directory.

The application candidate maps published R2 covers and gallery images to `/api/media/<asset-uuid>?v=<asset-uuid>`. The route rejects a mismatched version and reads only the current public/active R2 image plus its published product; it does not load the full catalog snapshot for each image request. Next 16.4.0's internal image fetch does not follow redirects from local routes, so versioned product media now streams the validated public image bytes with a 60-second cache policy. Versioned category media uses the same response path for public R2 images and short-lived Supabase-signed sources. Legacy unversioned proxy URLs retain their redirect behavior. The UUID query gives replacements a new optimizer cache key, and deleted or unpublished product assets resolve through current database state. Local route tests and a synthetic local Next Image request cover the 200-byte response; this is not evidence of a live R2/Supabase browser run. The new R2 path has not been deployed or exercised against Production.

The current Cloudflare connection lists only unrelated Chat/Library/Offer buckets and cannot read the Lamilia zone for `media.lamilialomi.com` (the zone read returned 403 in the targeted audit; the zone-list connector also failed). The Lamilia Supabase project has no Stage branch, and no Lamilia test R2 bucket or Stage-scoped S3 credentials are available. Production-only R2 credentials were not used for writes. Complete live acceptance still requires the correct Cloudflare account/zone with Zone Read, Zone Settings Read, Cache Rules Read, and Workers R2 Storage Read (or R2 Admin Read only for bucket configuration) access; an isolated Supabase Stage project/branch and R2 test buckets with `Object Read & Write` credentials scoped only to those test buckets; and Stage/Preview R2 application variables. A later host-specific cache-rule correction should set Browser Cache TTL to Respect Existing Headers for `media.lamilialomi.com`; do not change global rules or purge Production as part of this audit. A later API edit would require Zone Cache Rules Edit, Account Rulesets Edit, and Account Filter Lists Edit.
