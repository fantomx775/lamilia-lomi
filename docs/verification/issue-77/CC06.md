## Behavior

Verified adult members with current rules acceptance can set one heart per eligible artwork without unlocking its book. GET/PUT/DELETE `/api/community/artworks/:id/heart` use the current session only; writes require same origin and an empty body. Repeated explicit like/unlike intents are idempotent. Private service-only rows have a unique user/artwork key, RLS and revoked client privileges. Transactional triggers maintain a nonnegative aggregate without changing content revision or updated_at. Withdrawal, suspension and account cascade remove personal reactions. The account limiter persists120 requests/hour; raw liker identities never leave the server.

Safe public projections add aggregate count and session-only likedByMe. Viewer lookup is batched. Popular sorting uses count DESC, publication timestamp DESC, UUID DESC with a separate strict cursor; latest preserves its timestamp cursor. Both are bounded. Live score changes can move work between pages; client append deduplicates artwork IDs. Gallery, detail, creator and community PDP thumbnails have accessible pressed/pending states, visible rollback/retry and guest/verify/join CTAs. Curated images have no reaction controls.
